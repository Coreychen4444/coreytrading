# Journal file map

| Information | Local path |
|---|---|
| Fill/close events | `trade/us_stock/holding/events/<YYYY-MM>/trades.jsonl` |
| Decisions | `trade/us_stock/holding/events/decisions.jsonl` |
| Process scores | `trade/us_stock/holding/journals/scores.jsonl` |
| Narrative journals | `trade/us_stock/holding/journals/` |
| User-approved reusable methodology | private files generated from `trade/us_stock/strategy/*.example.*` |

All holding/event/journal paths are private runtime data and ignored by Git.
