```

broke   = episode 内 i 之前出现过 gate 下方的破位  (gate_backtest2 episode 构造)

①修复      broke
②上升续势  ¬broke ∧ trend_i == "up"  ∧ gate <  ath_i − δ
③箱体顶    ¬broke ∧ trend_i != "up"  ∧ gate <  ath_i − δ
④历史新高  ¬broke ∧ gate >= ath_i − δ
```

### 3d. ⚠️ 锁定 E 之后暴露的语义分歧（**跑之前必须知道，但不改判据**）

系统里有**两套「破位」定义**，它们在 live 上不一致：

| 定义 | 出处 | 判据 |
|---|---|---|
| **卡片相对**| `regime_transition.detect_transition` | `close < 卡片 stop_level` 连续 N 日 → demote |
| **结构绝对**| `gate_backtest.episodes_of`（= 锁定的 E） | 收 **60 日最低收盘**且 `close < MA60` |

实测分歧：**MRVL / MU 的卡片名叫 `B_repair_probe_189` / `B_repair_probe_848`
（转移机 /05 判过 demote），但按 E 在 120 日窗内 0 天深度破位 → 判③箱体顶。**
（已排除 cooldown 假象：不含 cooldown 重跑同样 0 天。原因是它们的跌幅没有创 60 日最低收盘。）

**不因此改判据。**理由：`ladder_entry` 的采纳样本**就是 `episodes_of` 造出来的**，
所以「①修复」这个采纳域的字面含义就是「`episodes_of` 那种 episode」。转移机因卡片
stop 被跌破而降级的卡，**若不满足 `episodes_of` 就是在已验证样本之外**—— 叫它什么名字
都不改变这一点。这条分歧本身进 §6：若本轮通过，两套定义要合并或显式分工。

### 3e. ⚠️ 第六个自由度：**样本怎么造**（锁 A–F 之后、写代码之前发现）

§4 那两句**互斥**，跑之前必须挑一个：

> 「复用 `gate_backtest2` 的 episode 构造」 vs 「样本 = 所有『首个 `close > gate`』触发日」

**gate2 的 episode 池 100% 是①，②③④在里面一个都不存在**—— 这是构造上的恒等式，不是抽样问题：

```
gate2/ladder_entry:  for i in episodes_of(...) → gate = cluster_gate(i, closes[i], ...)
cluster_gate 只返回上沿 > closes[i] 的簇        ⟹ closes[i] < gate  恒成立
D1 ∈ (i, i+WINDOW]，WINDOW = 120                ⟹ i ∈ [D1−120, D1)  恒成立
两条合起来正好是锁定的 E：120 日窗内存在 close < gate 的 episode ⟹ broke = True
```

所以「复用 gate2 的 episode 构造」这条路上，本预注册的四分类**退化成一格**。

| # | 待锁 | 候选 | 建议 |
|---|---|---|---|
| **G**| 样本构造 | ①沿用破位锚 + ②③④滚动 / **四类统一滚动上穿**| **统一滚动上穿**。理由：§3b-D 让①当**对照臂**，而对照臂的全部作用是「同一台机器上①能不能重现 ladder_entry 的 PASS」—— ①若来自另一套构造，它什么也控制不了，②③④失败时分不清是**类别**的错还是**构造**的错。代价要写明：①的 gate 是「D1 前一日的最近头顶簇」而非「破位日画定的簇」，数字不会与 `ladder_entry` 逐位相等 |

**G 已锁定（用户）= 统一滚动上穿**：

```

D1   = 首个 j 满足 closes[j] > G(j−1)                                 # 与 _fastlane ① 同拍：
                                                                      # G(j−1) > closes[j−1] 由构造保证 ⟹ D1 必是首日

录得后 cooldown = COOLDOWN(120)                                       # 直接用 episodes_of 的常数，不新增自由度
```

`G(j−1) is None`（头顶无簇）= gate 不存在 = 不触发（gate2 同语义）。

## 5. 判据（**运行前锁定**，按类分格独立执行）

沿用 `ladder_entry` §5 的五条，逐类各自成立才在该类采纳：

1. 风险单位：`风险N(FAST) − 风险N(SLOW)` 配对 CI90 上界 < 0
2. R：`R(FAST) − R(SLOW)` 配对 CI90 下界 > 0
3. 部署率 ≥ 80%
4. 绝对 expectancy CI90 上界 > 0
5. **止损率守卫（本轮新增，因为②③正是栽在这条上）**：止损率差 CI90 上界 **< +5pp**
   —— 与 escape_velocity 预注册同阈值，方便直接对话
6. Kish ≥ 30，否则该类报数据不足不裁决

任一不过 → **该类不采纳，`_fastlane` 在该类上维持 ×2**。四类各自独立，不互相外推。

### 12b. 主结论：**判别力不在类别上，在那条新加的止损率守卫上**

- **①风险N 四类全部显著降低**（−0.12N ~ −0.18N，CI 全部排除 0）——「早一天」确实拿到更紧的风险单位；
- **⑤止损率四类全部显著恶化**（+5.9 ~ +11.9pp，CI 全部排除 0，全部越过 +5pp 守卫）；
- 二者是**同一件事的两面**：入场离 `gate − 0.5N` 更近 ⇒ 风险单位更小 ⇒ 也更容易被打掉。
  这与 round-2b「stop 贴 gate = whipsaw 机器」是同一个机制，只是这次是**入场**贴过去的。

所以 **H-path 与 H0 都不是干净成立**：四类在①③④⑤上读数高度一致（不可区分 = H0 方向），
唯独②R 有可见排序 **③ −0.672 < ② −0.001 < ① +0.401 < ④ +1.245**。
⚠️ 这条排序是**观察不是裁决**（§7「不做事后分层挖掘」）—— 它没有改变任何一格的结论，
四格是被同一条判据⑤否掉的。**不得据此给②③④分级授权。**

### 12c. ⚠️ 对照臂给出的那个不舒服的发现（本轮最重要的一句）

①的 FAST 臂**数值上重现了 `ladder_entry` 的 C 臂**——两套完全不同的 episode 构造：

| | 部署 | 风险N | 止损率 | 收益均值 | R winsor | n / Kish |
|---|---|---|---|---|---|---|
| `ladder_entry` **C**（破位锚构造） | 86% | 1.07N | **67%**| +1.2% | +0.480 | 1,611 / 197 |
| 本轮 ①**FAST**（滚动上穿构造） | 86% | 1.16N | **65%**| +1.1% | +0.458 | 1,492 / 179 |

机器验过了 ⟹ ①失败不是构造的错。它失败是因为**本轮改掉了两件 `ladder_entry` 没做的事**：

1. **SLOW 也用 ladder。**`ladder_entry` 比的是「ladder@D1 vs **单点**@D2」——
   **执行结构与时点两个自由度被绑在一起**。本轮把执行结构固定住、只放「早一天」，
   D2 臂的 R 就从 +0.194（单点）升到 +0.320（ladder），差距的 CI 随即含 0。
   > 也就是说：**`fastlane_k=0.5` 进 live 所依据的那次比较，从来没有单独验过「早一天」。**
   > `ladder_entry` §0 自己写的是「**同一时点**起分档进」，但它的判据②比的是 C@**D1**vs
   > B1/B2@**D2**—— A 臂（D1 全额，同时点的那个真对照）报了数字却**没进任何一条判据**。
   > 它认为时点问题已由 `fastlane_repair_gate` 的「平局」结掉了，可那一轮测的是**全额**提前，
   > 不是 ladder 提前。这个缺口本轮才第一次被填上。
   >
   > ⚖️ **对 `ladder_entry` 要公道**：**ladder 那一半是站得住的**—— 它自己 §10a 的同时点对照
   > A(+0.283) vs C(+0.480) 方向明确。本轮质疑的**只是时点那一半**，不是分档。
2. **⑤止损率守卫是本轮新加的。**`ladder_entry` 自己那张表上 C 67% vs B1 56% = **+11pp**
   已经印着，只是**五条判据里没有一条管它**。本轮把它设成硬守卫，①当场不过。

**这不是对 `ladder_entry` 的翻案**（§3b-D：①只复现不裁决；两份预注册、判据不同）。
它是一条**新的、够格立项的证据**：live 的 `fastlane_k=0.5` 建立在一个混淆了两个自由度的
对照上，而把自由度拆开之后，「早一天」买到的是更紧的风险单位 + 更高的止损率，R 上不显著。
**处置建议：单独立一份预注册（ladder@D1 vs ladder@D2，判据含止损率守卫），在那之前不动 live。**

> ⚠️ **当日修正（`ladder_timing_design.md` §9c）**：上面这段的**后半错了**。
> 拆开自由度之后在 `ladder_entry` 自己的池上（量腿 off，1995+，n=1,477）
> **R(FAST−SLOW) = +0.226 CI90 [+0.069, +0.391]，显著为正**，ROLL 独立复现 +0.221。
> 「R 的 CI 含 0」只成立于**带量腿**的池（本轮①就是那个池）—— 是总体依赖的，不是一般性的。
> **成立的是前半**（对照混淆了两个自由度）**与止损率那一条**（三格 +8.9~+10.6pp，全部远离守卫）。
> 「早一天」的真实形状是**一笔交易**：更紧的风险单位 + 更好的 R，换 +10.6pp 止损率 ——
> 它是被**守卫**否掉的，不是被收益否掉的。而那条守卫的口径(ITT)与阈值(搬自 escape 的不同止损模型)
> 都未经校准，见 `ladder_timing_design.md` §9d/§9e。

### 12e. 限制（写在前面，不等下一个人来发现）

- **判据②在本构造下功效偏低**：R = 收益/风险比例，档位成交贴近 `gate` 地板时分母可以很小 ⇒
  重尾。①的 CI 宽达 1.19（`ladder_entry` 同判据只有 0.28）。**④那个「②✓」的下界只有 +0.019，
  脆**；它没救下④（⑤仍否），但不要单独引用「④的 R 显著为正」。
- **⑤是 policy 口径**：SLOW 未入场记 `stopped=False`，而 FAST 必定入场 ⇒ 判据⑤对 FAST 偏严。
  方向正确（守卫本该难过）且与 `escape_velocity` 同口径；SLOW 入场率 87–93% 已一并报出。
- **`ath` 是最高收盘、`gate` 是 pivot 高点**（cluster 由 H+L pivot 组成）—— 两个基准不同，
  轻微偏向把 gate 判进④。这是 §3 字面写死的口径，照跑，记在此。
- **样本自 2006 起**（量腿要基准）。gate2 的 1995+ 那一段在本轮不存在。
- 存续票池：偏向高估突破跟随 ⇒ 四类**都不过**这个结论更稳，不更松。
