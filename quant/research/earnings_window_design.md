# 财报窗口缩仓规则 — 预注册（起草，**运行前锁定**）

**状态**：✅ **已跑完并裁决→ 四臂无一通过**。
缩仓规则**有效但不够**：把超限率从 18.5% 砍到 8.0%（显著），却进不了 [1%,4%] 带。
按 §7，40% 名义上限须相应处理。见 §10。
**起因**：用户  定单一正股名义上限 40% NAV 之后，`shock_budget_design.md` §2.3b
实测：单票 4N 事件在 40% 仓上是 **13–21% NAV 一天**，**已超过 15% 总预算本身**。
财报窗口规则因此从「可选」变成**承重**。
**用户的方法要求（原话）**：「窗口多长这取决于每个票的历史数据统计，
决定减仓窗口，不是我口头随心说一个数。」

## 0. 窗口长度：**已由数据定，不是本轮的假设**

探路扫描（142 票 / 2,727 个财报事件 / 基线样本 806,537，基线 = 距财报 >7 日）：

| 相对反应日 | \|日内变动\| 中位 | 中位/基线 | >2N 占比 |
|---|---|---|---|
| T−5 ~ T−1 | 0.41–0.44N | **0.99–1.05×**| 0.9–1.5% |
| **T+0（反应日）**| **1.46N**| **3.51×**| **36.2%**|
| T+1 | 0.54N | 1.29× | 2.8% |
| T+2 及以后 | 0.39–0.44N | 0.93–1.04× | ~1% |

**结论（锁定为定义，不再检验）**：

- **财报前完全没有风险抬升**—— T−5 到 T−1 与基线无统计区别。
  「财报前一周开始缩仓」在数据上找不到依据，**不采用**
- **风险全部集中在反应日 T+0**，T+1 有轻微残留，T+2 归零
- **缩仓窗口 = T+0 单日**；T+1 作敏感性并列报告，不进主规则

**执行时点（锁定）**：绝大多数是 AMC（盘后），跳空发生在夜里，反应日开盘已来不及 →
**必须在反应日的前一个交易日收盘前减完**，~~反应日 **T+1 收盘后**恢复~~ **T+1 起恢复全额**
（原文与上一行「T+0 单日」自相矛盾， V4 案更正；live `core/earnings.py` 即 T+0 单日）。
BMO 的情形同式（反应日 = pub 日，仍是前一收盘减完）。窗口 ≈ 2 个交易日。

## 1. 要回答的问题

**反应日该把仓位缩到多少？**探路显示这个数**必须 per-ticker**：

| 标的 | 事件数 | 财报日跌幅 p98 | 相对普通日（1.94N） |
|---|---|---|---|
| **NVDA**| 19 | **1.92N**| **1.0×**（与普通日无区别） |
| MU | 20 | 3.81N | 2.0× |
| MSFT | 19 | 4.88N | 2.5× |
| MRVL | 20 | 4.93N | 2.5× |
| INTC | 20 | 6.79N | 3.5× |
| **AAOI**| 19 | **9.66N**| **5.0×**|

统一比例会同时错两头：白白缩掉 NVDA，又缩不够 AAOI。

⚠️ **但每票只有 19–20 个事件**，p98 实际上就是「最坏那一个」——估计噪音极大。
**本轮的真问题不是「要不要 per-ticker」，而是「per-ticker 该怎么估才不是在拟合噪音」。**

## 2. 缩仓公式（锁定）

要求：**财报日的单笔风险占用不得高于它在普通日的占用**。

```
w_normal × X_normal × vol  =  w_earn × X_earn × vol
⇒  w_earn = w_normal × (X_normal / X_earn)          X_normal = p98 ≈ 1.94N
```

即缩仓比例 = `X_normal / X_earn`。NVDA 比例 ≈1.0（不缩），AAOI ≈0.20（缩到五分之一）。

## 3. 估计量（**四臂，运行前锁定，不加第五个**）

| 臂 | `X_earn` 的估计 |
|---|---|
| **D 不缩仓**| 现状对照（`X_earn = X_normal`，即不动仓） |
| **A 池级 p90**| 全池财报日跌幅 p90 = **3.00N**，所有票同一个数 |
| **B 单票 p98**| 该票自己历史财报日跌幅的 p98（= 探路那一列） |
| **C 收缩估计**| `X = λ·单票 + (1−λ)·池级`，`λ = n/(n+n₀)`，**n₀ = 10 锁定**（约等于"要 10 个事件才信一半自己"） |

## 4. 样本外协议（**关键，锁定**）

**估计只用被测事件之前的历史**（expanding window）：测第 k 个财报事件时，
`X_earn` 只由第 1..k−1 个事件估计。**先验事件 < 8 个 → 该事件不计入裁决**
（B/C 臂无从估计），并单独报告这类事件占比。

**回退规则（锁定）**：先验事件 <8 的票（如 NBIS 这类新股）一律走 **A 池级 p90**。
这是规则的一部分，不是数据缺失。

## 5. 判据（**运行前锁定**）

采纳某个估计量，当且仅当**全部**成立：

1. **控制力**：样本外，「实际财报日损失 > 该仓位普通日预算占用」的频率落在
   **[1%, 4%]**（= 普通日 p98 尾率 2% 的 0.5×–2×）。
   高于 4% = 没控住；**低于 1% = 缩过头**（那是在付无谓的保费）
2. **打赢不缩仓**：该臂的超限频率**显著低于 D 臂**（bootstrap CI90 排除 0）
3. **保费有上限**：因缩仓而放弃的财报日**收益**（缩仓比例 × 该日正收益）
   平均 ≤ **该臂避免的损失的 100%**—— 即不能为了避一块钱的亏而丢掉超过一块钱的赚
4. **Kish ≥ 30**

全部满足者中，取**平均缩仓幅度最小**者（同样控住风险，少缩就是少付保费）。
无一满足 → **不采纳，记录否定结果**，40% 名义上限须相应下调（见 §7）。

### 10a. 但这是一个「有效但不够」的失败，不是「没用」

- **不缩仓时，每 5.4 个财报日就有 1 个**（18.52%）冲破该仓位的普通日预算。
  这坐实了 §0 立项的前提。
- 三个臂都把它**砍掉一半以上**（→8–10%），且**全部显著**（CI90 排除 0）。
- **保费比 ≈ 1.00**：少赚几乎恰好等于少亏。因为池级财报日跌幅中位是 **−0.00N**（对称）
  —— **缩仓进财报在期望上是中性的，你花的不是收益，是换来了方差压缩**。
  这条是意外的好性质，值得单独记住。
- 但最好的 B 臂 7.93% 仍是上界 4% 的 **2 倍**。原因：财报日尾部太肥，
  19–20 个事件估出来的 p98 根本够不到实际尾部。

### 10b. B vs C：单票 p98 略胜收缩，但差异在噪音里

B（7.93%）与 C（8.37%）相差 0.44pp，而两者的 CI 高度重叠。
**§6 预判「B 大概率输给 C」没有兑现，但也没有被推翻**—— 42.1% 的事件走了回退臂，
per-ticker 的差异只在 58% 的样本上真正起作用，本轮分不出高下。

### 10e. 裁决：**路 A**（用户  批准）


### 10h. 减仓半边的基数 = 名义上限（修回归，COHR 实证）

入场半边住 `available_cap(event_shrink=…)`；**减仓半边**（T-1 日已有敞口超过明日
缩仓后上限 → 点名减多少）住 `portfolio_brief.earnings_trim_signal`（ledger A2，
 接线）。两边的基数都必须是 §10e 裁决字面的**名义上限 40%**：

```
明日上限 = NOTIONAL_CAP(40%) × NAV × shrink_ratio(x_earn)
```

**基数不取 regime cap。**regime cap 答的是「能不能进 / 还能加多少」——持仓卡
`cap 0` = **无加仓授权**（NBIS 规则）——而本规则按 §10e 的边界声明
只改「那一天能有多大」，不改「能不能进」（`core/earnings.py` 顶部同款措辞）。
两个轴互借就会得出「持有 = 未授权 ⇒ 反应日必须清仓」这种没人裁决过的结论。

**回归经过（形状 = 改一个调用点，下游的 None 检查静默失效）**：接线时基数取的是
`position_budget.class_cap_usd`（= NAV × regime cap）——分类轴退役前 confirmed 卡上
它与名义上限恰好相等，区别看不出来；为 cap 0 写的 `if base is None` 回退看着也对。
 分类轴退役当天，`position_budget` 改成 **cap 0 也照出预算行**
（`class_cap_usd` = `0.0` 而不是 `None`，那一改本身是对的，修的是「预算行整条消失 →
can_add 失败为开」），于是回退再没触发过，而基数从此恒为 0。

live 后果（heartbeat 抓到）：COHR 卡 `[持仓·无加仓授权] cap 0`，20 股
$6,854，反应日 8/13 → 播「减 $6,854 ≈ **20 股**」= 清仓；裁决口径是减到 ≈$3,5xx ≈
**10 股**。告警没静音，是量级错了一倍 —— 比静音更难发现，因为它看起来在正常工作。

回归钉在 `tests/report/test_earnings_trim_alert.py::test_cap_zero_holding_does_not_collapse_target_to_zero`
（连着 `position_budget` 一起跑：任何人把基数重新接回预算行，那条当场红）。
