# 技术交易框架学习计划

## 文档定位

这份计划不是技术分析教材，而是一份供 AI 学习的技术交易知识地图（Syllabus）：规定 AI 应系统学习哪些概念、按照什么层级组织，以及最终怎样接入现有交易系统。

整体学习与决策主链：

\[
\boxed{
Market\ Context
\rightarrow
Market\ Structure
\rightarrow
Price\ Action/Pattern
\rightarrow
Volume/Volatility
\rightarrow
Indicators
\rightarrow
Signal
\rightarrow
Execution
}
\]

AI 必须区分：**原始市场信息、结构信息、确认信息、衍生指标**，避免简单把 RSI、MACD、均线等高度相关指标当成独立信号重复加分。

---

系统学习美股技术分析，并最终将技术分析整合进入既有交易系统，形成：

# 给 AI 的学习原则

以下原则应作为 AI 学习技术分析时的最高规则：

**1. Price first, Indicator second**

价格和成交量是原始信息，技术指标是衍生信息。

**2. Context > Signal**

任何技术信号必须放在市场环境和市场结构中解释。

**3. Structure > Pattern Name**

研究形态背后的结构，而不是机械记忆形态名称。

**4. Setup ≠ Trigger**

交易机会存在，不代表已经达到入场条件。

**5. Confirmation ≠ Prediction**

MACD、RSI、成交量等主要用于确认和量化，而不是神奇预测未来。

**6. Avoid Double Counting**

高度相关的指标不能被当成多个独立证据。

**7. Signal ≠ Position**

技术信号决定是否值得交易；仓位大小还需要结合置信度、波动率、风险预算和组合风险。

**8. Every Setup Must Be Falsifiable**

任何技术 Setup 都必须存在明确的 invalidation condition。

**9. Every Rule Must Be Quantifiable**

最终尽可能把自然语言规则转化为机器可识别和可回测规则。

**10. Every Signal Must Be Tested**

未经历史统计、样本外验证和稳健性测试的技术信号，只能被视为 hypothesis，而不是有效 edge。

# 六大阶段总览

整套学习路线可以进一步压缩为 6 个大阶段：

\[
\boxed{
I.\ Understand\ Market
}
\]

Context → Regime → Structure

\[
\boxed{
II.\ Read\ Market
}
\]

Price Action → Pattern → Volume → Volatility

\[
\boxed{
III.\ Quantify\ Market
}
\]

Indicators → Relative Strength → Breadth

\[
\boxed{
IV.\ Build\ Signal
}
\]

Setup → Trigger → Confirmation → Signal Score

\[
\boxed{
V.\ Trade\ Signal
}
\]

Position → Pyramiding → Risk → Exit

\[
\boxed{
VI.\ Validate\ Edge
}
\]

Quantification → Backtest → Robustness → Signal Independence

这套结构不是简单的“技术指标百科”，而是在强制 AI 理解一个核心关系：

\[
\boxed{
技术分析不是寻找更多指标，
而是从市场状态
\rightarrow 结构
\rightarrow 行为
\rightarrow 确认
\rightarrow 信号
\rightarrow 决策
}
\]

技术分析最终应作为一个 **Technical Engine**接入现有交易系统，而不是成为独立于基本面、仓位管理和风控之外的“看图模块”。
