# Private knowledge workspace

This subtree contains user-specific research, evidence and conclusions. The public repository provides structure only.

The AI should create a research card only from sources the user supplied or authorized. It must preserve source dates, separate claims from inferences, record contradictory evidence, and mark unanswered questions. Use `research/research-card.example.md` as the starting schema.

Generated research cards and indexes are private because their subjects and priorities can reveal an active portfolio or watchlist.
