# Agent entry point

This is a compatibility entry point, not a second project contract.

Before working in this repository, read `CLAUDE.md` in full with your file-reading tool. It is the authoritative project contract for every model and runtime; follow it together with the user's explicit instructions and any more specific instruction file that applies to the files being changed.

Code placement and dependency rules live in `quant/README.md`. The four domain roles, model routing, frozen-input workflow and controlled submission interface are documented in `agents/README.md`. For a fresh clone, infrastructure or a private workspace, read `AI_BOOTSTRAP.md` first; for private trading data, continue with `trade/README.md` and every relevant descendant `README.md`.

Do not rename, delete, summarize, or duplicate `CLAUDE.md` into this file. One complete contract prevents instruction drift. A role's research result never grants permission to place orders, change broker truth, send messages or register schedules.
